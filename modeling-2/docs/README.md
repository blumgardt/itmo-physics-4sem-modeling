# Моделирование дифракции Фраунгофера

## Описание работы

В данной лабораторной работе реализована программа для моделирования **дифракции Фраунгофера** от двумерного объекта произвольной формы. Объект задаётся амплитудной маской `t(x, y)` – это функция, которая в каждой точке плоскости объекта говорит, какая доля падающей световой волны проходит сквозь него (1 – прозрачно, 0 – непрозрачно).

Программа вычисляет распределение интенсивности `I(X, Y)` в плоскости наблюдения, расположенной на расстоянии `L` от объекта, при освещении плоской монохроматической волной с длиной `λ`.

В программе задаются:

- `λ` – длина волны падающего излучения,
- `L` – расстояние до плоскости наблюдения,
- `N` – размер расчётной сетки (256, 512 или 1024),
- форма апертуры и её геометрические параметры (`W`, `H`, `T`, число щелей).

---

## Физическая основа работы

Дифракция Фраунгофера – это явление дифракции в **дальней зоне**: волна, прошедшая сквозь объект, отойдя достаточно далеко, формирует на экране картину, которая математически связана с самим объектом через двумерное преобразование Фурье.

Условие применимости – малое число Френеля:

`N_F = a² / (λ · L) ≪ 1`

где `a` – половина характерного размера апертуры. Если `N_F > 0.1`, мы выходим из режима дальней зоны и приближение Фраунгофера становится грубым. Программа сама вычисляет `N_F` и предупреждает, если он велик.

---

## Теоретические сведения

Распределение комплексной амплитуды поля в плоскости наблюдения:

```math
U(X, Y) = [e^{ikL} · e^{ik(X²+Y²)/2L}] / (i·λ·L) · ∫∫ t(x, y) · exp(-i·2π·(Xx + Yy)/(λL)) dx dy
```

где `k = 2π/λ` – волновое число. Внутренний двойной интеграл – это и есть преобразование Фурье от `t(x, y)` на пространственных частотах `f_x = X/(λL)`, `f_y = Y/(λL)`.

Интенсивность, которую видит экран:

`I(X, Y) = |U(X, Y)|²`

При взятии квадрата модуля префакторы `e^{ikL}` и `e^{ik(X²+Y²)/2L}` исчезают (их модуль равен 1), поэтому форма картины полностью определяется модулем Фурье-образа маски.

### Канонические случаи и их реализация в коде

Для верификации программы используются формы, у которых дифракционная картина имеет известное аналитическое выражение. Параметры `apW`, `apH`, `apD` (управляются клавишами `W`, `H`, `T`) интерпретируются по-разному в зависимости от выбранного пресета – вся геометрия маски собирается в функции `buildAperture` (`cmd/diffraction/main.go`).

#### Прямоугольное отверстие `apW × apH`

```go
case apRect:
    if math.Abs(x) <= halfW && math.Abs(y) <= halfH {
        v = 1
    }
```

`t(x, y) = 1` внутри прямоугольника, иначе `0`. Интенсивность на экране: `I(X, Y) ∝ sinc²(apW·X/λL) · sinc²(apH·Y/λL)`, первый нуль вдоль `X` – на расстоянии `λL/apW` от центра. **Влияние параметра:** если уменьшить `apW`, картина расширяется по `X` обратно пропорционально – узкий объект даёт широкий спектр, фундаментальное свойство Фурье-преобразования.

#### Круглое отверстие радиуса `apW/2`

```go
case apCircle:
    if x*x + y*y <= halfW*halfW {
        v = 1
    }
```

Картина Эйри: `I ∝ [2J₁(v)/v]²`, где `J₁` – функция Бесселя первого рода, `v = π·apW·r/(λL)`. Первое тёмное кольцо: `r₁ = 1.22·λL/apW` – это и есть критерий Рэлея, фундаментальный предел разрешения телескопов и микроскопов. **Влияние параметра:** уменьшение `apW` раздувает диск Эйри.

#### Двойная щель (опыт Юнга)

```go
case apDoubleSlt:
    if math.Abs(y) <= halfH {
        if math.Abs(math.Abs(x)-apD/2) <= apW/2 {
            v = 1
        }
    }
```

Условие `|x − apD/2| ≤ apW/2 ∨ |x + apD/2| ≤ apW/2` задаёт **две щели** шириной `apW` каждая, с центрами на `x = ±apD/2`. То есть `apD` – это центр-в-центр расстояние между щелями. Интенсивность: `I ∝ sinc²(apW·X/λL) · cos²(π·apD·X/λL)` – `sinc²`-огибающая от одной щели умножена на интерференционный множитель от двух источников. Период полос: `λL/apD`. **Влияние параметра:** увеличение `apD` сжимает интерференционные полосы – знаменитый эффект Юнга.

#### Дифракционная решётка из `apNSlits` щелей с периодом `apD`

```go
case apGrating:
    if math.Abs(y) <= halfH {
        totalSpan := float64(apNSlits-1) * apD
        leftEdge := -totalSpan / 2
        rel := x - leftEdge
        if rel >= -apW/2 && rel <= totalSpan+apW/2 {
            idx := math.Floor(rel/apD + 0.5)
            if idx >= 0 && idx < float64(apNSlits) {
                slitCenter := leftEdge + idx*apD
                if math.Abs(x-slitCenter) <= apW/2 {
                    v = 1
                }
            }
        }
    }
```

Решётка располагает `apNSlits` одинаковых щелей шириной `apW` через равные промежутки `apD`, симметрично относительно центра. Главные максимумы – в направлениях `sin θ_m = m·λ/apD`. **Влияние `apNSlits`:** ширина главных максимумов пропорциональна `1/apNSlits`. Чем больше щелей, тем острее пики – на этом основан принцип спектроскопа: больше штрихов решётки → выше разрешающая способность по `λ`. Если убрать суммирование по щелям (`apNSlits = 1`), получится простая `sinc²`-картина одной щели.

#### Крест

```go
case apCross:
    if (math.Abs(x) <= halfW && math.Abs(y) <= halfH) ||
        (math.Abs(x) <= halfH && math.Abs(y) <= halfW) {
        v = 1
    }
```

Объединение двух перпендикулярных прямоугольников (логическое ИЛИ): горизонтальная полоса размером `apW × apH` плюс вертикальная – её же, повёрнутая на 90° (`apH × apW`). Дифракционная картина – суперпозиция двух перпендикулярных `sinc²`-полос. **Влияние:** если поменять `apW ↔ apH`, маска поворачивается на 90°, картина – тоже.

#### Кольцо (annulus)

```go
case apRing:
    r2 := x*x + y*y
    if r2 <= halfW*halfW && r2 >= (apD/2)*(apD/2) {
        v = 1
    }
```

Внешний радиус – `apW/2`, внутренний – `apD/2`. Картина – разность двух картин Эйри (от внешнего и внутреннего кругов). **Влияние `apD`:** при `apD → 0` это просто диск Эйри; при `apD → apW` остаётся тонкое кольцо, и картина асимптотически переходит в осциллирующую `J₀²(πapW·r/λL)` – модель телескопа с центральным экраном (Кассегрена).

#### Paint mode (`apPaint`) – произвольная маска

```go
case apPaint:
    if paint != nil {
        v = paint[j*N+i]
    }
```

Маска полностью задаётся пользователем мышью – `paintBuf` содержит значения `t(x, y) ∈ {0, 1}` напрямую. Никакого аналитического выражения для картины здесь нет – программа честно считает Фурье-образ нарисованной формы. Этот режим и есть ответ на исходное требование задачи: «объекты произвольной формы».

Все остальные пресеты в этом смысле – лишь тесты с известным аналитическим решением для верификации, что общий численный метод работает правильно.

## Дискретизация и численный метод

Маска `t(x, y)` дискретизируется на сетке `N × N` с шагом `dx` по обеим осям. Преобразование Фурье вычисляется быстрым алгоритмом – БПФ (FFT, Fast Fourier Transform) Кули–Тьюки по основанию 2.

### Связь параметров сетки и физических координат

По свойствам дискретного преобразования Фурье шаг по пространственной частоте после БПФ равен `1/(N·dx)`. Пространственная частота связана с координатой на экране как `f_x = X/(λL)` (см. ядро Фраунгофер-формулы). Перемножая, получаем шаг по `X` в плоскости наблюдения:

```
DX = λL / (N · dx)
```

Соответственно полное окно наблюдения:

```
W_obs = N · DX = λL / dx
```

Заметьте: `W_obs` **не зависит от `N`** – оно определяется только `λ`, `L` и шагом сетки в объекте. При увеличении `N` (на том же `dx`) окно остаётся прежним, но детализация удваивается – видны более тонкие порядки. В коде окно вычисляется и выводится на экран:

```go
Wobs := lambdaShown * g.L / g.dx
text.Draw(screen, fmt.Sprintf("window: %s", formatLength(Wobs)), ...)
```

### Почему `N` обязательно – степень двойки

Алгоритм Кули–Тьюки радикса 2 работает только при `N = 2^k`: на каждом шаге массив рекурсивно делится пополам. Любая нестепень двойки потребовала бы либо смешанный радикс, либо zero-padding до ближайшей `2^k`. В программе поэтому разрешены только три значения `N`:

- `N = 256` – быстрый предпросмотр (БПФ менее 5 мс),
- `N = 512` – рабочий режим по умолчанию,
- `N = 1024` – высокая детализация, видны слабые порядки.

### Структура БПФ в коде

**Twiddle-факторы** `w_k = e^{−i·2π·k/N}` – поворотные комплексные множители «бабочек» БПФ. Они кешируются в `twiddles(N)`, чтобы синусы и косинусы не пересчитывались на каждый кадр:

```go
for k := 0; k < N/2; k++ {
    theta := -2 * math.Pi * float64(k) / float64(N)
    t[k] = complex(math.Cos(theta), math.Sin(theta))
}
```

Без этого кеша на каждом пересчёте уходило бы `O(N² log N)` тригонометрических вызовов – выкидывание кеша сразу делает программу в разы медленнее.

**Bit-reverse** (`bitReverse(data)`) – перестановка элементов входного массива в битово-обращённом порядке. Это нужно потому, что итеративный Кули–Тьюки получает на вход массив, уже разнесённый по чётным/нечётным индексам рекурсивно. Без этой перестановки `fft1D` выдаст результат с переставленными бинами – картина «расползётся» хаотически.

**Бабочка** – элементарная операция БПФ:

```go
t := tw[k*step] * data[i+k+half]
u := data[i+k]
data[i+k]      = u + t
data[i+k+half] = u - t
```

Здесь две соседние «половинки» массива объединяются с поворотом – это и есть тот самый шаг, который превращает `O(N²)` ДПФ в `O(N log N)` БПФ.

**Двумерное БПФ** факторизуется математически точно: сначала одномерное БПФ по каждой строке, потом – по каждому столбцу. Это позволяет параллельно обрабатывать строки/столбцы через `sync.WaitGroup` на `runtime.NumCPU()` горутин:

```go
for w := 0; w < nWorkers; w++ {
    wg.Add(1)
    go func(s, e int) {
        defer wg.Done()
        for r := s; r < e; r++ {
            fft1D(data[r*N:(r+1)*N], tw)
        }
    }(start, end)
}
wg.Wait()
```

Если убрать параллелизм (заменить на один цикл по всем строкам), при `N = 1024` пересчёт картины замедлится в `NumCPU` раз – на 8-ядерном процессоре это разница между 30 мс и 240 мс, и интерактивность теряется.

### Шахматный сдвиг и центрирование нулевой частоты

Стандартное БПФ кладёт нулевую частоту (центр картины) в индекс `0`, высокие частоты – в середину массива. Чтобы центр оказался в центре сетки, обычно применяют операцию `fftshift` – перестановку четырёх квадрантов матрицы после БПФ. Здесь используется математически эквивалентный, но более дешёвый трюк: умножение **входной** маски на шахматный паттерн `(−1)^(m+n)`.

```go
if (i+j)&1 == 1 {
    v = -v
}
```

Свойство: умножение во временной/пространственной области на `e^{iπ·n}` = `(−1)^n` сдвигает спектр на `N/2`. Применённое и по `x`, и по `y`, оно центрирует ДПФ-результат на `(N/2, N/2)` за один проход во время заполнения маски. Корректность проверяется тестом `TestFFT2DCheckerboardCentersDC`. Если убрать эту строку, центральное яркое пятно дифракции окажется в углу окна, а не посередине.

### Нормировка интенсивности на `I_max`

После БПФ интенсивность `|U|² = re² + im²` имеет произвольный абсолютный масштаб: префакторы `1/(iλL)` и фазовые множители из Фраунгофер-формулы отброшены, поскольку для формы картины они не важны (`|e^{iφ}| = 1`). Чтобы изображение нормально выглядело на экране независимо от размера апертуры и длины волны, программа находит максимум по всему полю и работает с относительной интенсивностью `I / I_max ∈ [0, 1]`:

```go
Imax := 0.0
for _, v := range g.intensity {
    if v > Imax { Imax = v }
}
```

**Влияние:** при крупной апертуре (большое `apW`) центральное пятно даёт огромный пик – без нормировки оно бы «выгорело» до белого, а боковые порядки утонули бы в шуме разрядности байта. При мелкой апертуре, наоборот, всё стало бы почти чёрным. Нормировка платит за это потерей информации об абсолютной яркости, но для качественной картины дифракции это не важно.

## Что именно показывает программа

На экране отображаются:

- **левая панель** – амплитудная маска `t(x, y)` (объект, через который проходит свет);
- **правая панель** – распределение интенсивности `I(X, Y)` в плоскости наблюдения;
- **строка статуса** – текущие значения `λ`, `L`, `N`, число Френеля `N_F`, параметры апертуры и время пересчёта одного кадра.

### Цветовое отображение

Поддерживаются два режима:

1. **Монохромный** (`mono+plasma`) – одна длина волны, интенсивность раскрашивается палитрой "plasma" (от фиолетового через красный к жёлтому) с линейной интерполяцией между опорными цветами (`plasmaColor`). Соответствует физике эксперимента с лазером одного цвета.
2. **RGB** – наложение картин для трёх длин волн (650/550/450 нм) в каналы R, G, B одного изображения. В этом режиме на дифракционной решётке видна хроматическая дисперсия – порядки расходятся в радугу, как на CD-диске, потому что направления главных максимумов `sin θ_m = m·λ/d` зависят от λ.

#### Как реализован RGB

БПФ вычисляется **один раз** (при текущей `λ`), потому что значения `|U|²` сами по себе не зависят от длины волны – λ входит только в связь между индексом массива и физической координатой `X` на экране:

```
X(k) = (k − N/2) · λL / (N·dx)
```

Чтобы получить интенсивность для другой длины волны `λ_c` в той же физической точке `X`, нужно взять значение из массива по индексу, масштабированному отношением `λ_R/λ_c` (за окно наблюдения берётся самая длинноволновая компонента – красная, чтобы и красный, и зелёный, и синий все три уместились в один и тот же экран):

```go
lambdas := [3]float64{lambdaR, lambdaG, lambdaB}
for c := 0; c < 3; c++ {
    scale := lambdaR / lambdas[c]
    kx := half + (float64(i)-half)*scale
    ky := half + (float64(j)-half)*scale
    val := bilinear(g.intensity, N, kx, ky)
    ...
}
```

Для красного `scale = 1` – значения берутся «как есть»; для синего `scale ≈ 1.44` – выборка идёт с дальних бинов, потому что синий физически «сжат» к центру. Так как `scale` – нецелое, координаты `kx, ky` попадают между четырёх соседних отсчётов FFT, и применяется **билинейная интерполяция**:

```go
return a*(1-fx)*(1-fy) + b*fx*(1-fy) + c*(1-fx)*fy + d*fx*fy
```

Если убрать билинейную интерполяцию (округлять `kx, ky` до целого), в RGB-картине появится видимый пиксельный шум – особенно у синего канала, где `scale` далеко от 1. Билинейная сглаживает выборку и даёт чистое наложение каналов.

### Преобразование яркости

Дифракционная картина имеет очень большой динамический диапазон: центральное пятно бывает в тысячи раз ярче боковых порядков. Для того чтобы слабые порядки были видны, в коде (`transformIntensity`) применяется одно из трёх преобразований:

```go
switch mode {
case dispLog:
    return math.Log1p(logAlpha*v) / math.Log1p(logAlpha)
case dispGamma:
    return math.Pow(v, 1.0/gamma)
default:
    return v
}
```

где `v = I / I_max ∈ [0, 1]`.

- **`log`**: `disp = log(1 + α·v) / log(1 + α)`. Параметр `α = logAlpha` (по умолчанию `1e3`) задаёт степень сжатия: чем больше `α`, тем сильнее «вытягиваются» слабые значения. При `α → 0` log-преобразование вырождается обратно в линейное. Это самый агрессивный режим – позволяет видеть порядки в `10³–10⁴` раз слабее центрального пятна.
- **`gamma`**: `disp = v^(1/γ)`. При `γ = 1` – линейная шкала; при `γ > 1` тёмные значения «растягиваются» (типичная коррекция для дисплеев – `γ ≈ 2.2…2.4`). Коэффициент управляется клавишей `G / Shift+G` в диапазоне `[1.0, 6.0]`.
- **`linear`**: `disp = v` напрямую – никакого сжатия. В этом режиме видны только самые яркие пятна; слабые порядки сольются с фоном.

Если убрать `transformIntensity` целиком (сразу писать `I/I_max` в пиксель), картина превратится в почти чёрное поле с одной яркой точкой в центре – именно поэтому используется `log` по умолчанию.

- `dx = 1 мкм`,
- `N = 512`,
- апертура – прямоугольник `60 мкм × 40 мкм`.

При этих значениях окно наблюдения составляет около 275 мкм, шаг ~0.5 мкм/пиксель.

## Управление программой

### Выбор апертуры

- `1` – прямоугольник,
- `2` – круг,
- `3` – двойная щель (опыт Юнга),
- `4` – дифракционная решётка,
- `5` – крест,
- `6` – кольцо,
- `M` – paint mode (рисование маски мышью).

### Параметры формы

- `W / Shift + W` – параметр `W` (ширина прямоугольника, радиус круга/кольца, ширина щели);
- `H / Shift + H` – параметр `H` (высота прямоугольника, высота щели);
- `T / Shift + T` – параметр `T` (расстояние между щелями, период решётки, внутренний радиус кольца);
- `[ / ]` – уменьшить / увеличить число щелей в решётке.

### Физические параметры

- `+ / -` – изменить длину волны в пределах **видимого диапазона 380–780 нм** (фиолетовый – красный). За этими границами свет невидим глазом, поэтому в программе мы ограничили λ:

  ```go
  g.lambda += 10e-9
  if g.lambda > 780e-9 { g.lambda = 780e-9 }
  ...
  if g.lambda < 380e-9 { g.lambda = 380e-9 }
  ```

  Шаг – 10 нм. Влияние λ на картину: при увеличении λ всё окно наблюдения `W_obs = λL/dx` растягивается пропорционально, и картина «раздувается»; при уменьшении – сжимается.
- `L / Shift + L` – увеличить / уменьшить расстояние до экрана (шаг 5 см, диапазон 5 см … 5 м). Влияние `L` – то же, что у `λ`: окно наблюдения линейно по `L`. Кроме того, при малом `L` растёт число Френеля `N_F = a²/(λL)`, и приближение Фраунгофера ломается – программа предупреждает об этом.
- `N` – переключить размер сетки (256 → 512 → 1024 → 256 …). На картину влияет только детализация (больше `N` – видно больше мелких порядков), но **не размер окна наблюдения**.

### Режим отображения

- `C` – переключить mono ↔ RGB,
- `D` – переключить log → gamma → linear,
- `G / Shift + G` – увеличить / уменьшить параметр `γ`.

### Прочее

- `S` – сохранить дифракционную картину в PNG;
- `R` – сброс параметров (в paint mode – очистка маски);
- в paint mode: левая кнопка мыши – рисовать, правая – стирать.

## Физический смысл получаемой картины

### Соотношение размеров

Чем уже отверстие, тем шире дифракционная картина – это фундаментальное свойство преобразования Фурье. Узкий прямоугольник в плоскости объекта даёт растянутую `sinc`-картину поперёк него, и наоборот.

### Двойная щель и решётка

Для двух щелей видны параллельные тёмные полосы – интерференция от двух источников. Расстояние между полосами обратно пропорционально расстоянию между щелями. Для дифракционной решётки тёмные полосы вырождаются в резкие точечные максимумы, и чем больше щелей, тем тоньше эти максимумы – это используется в спектроскопии.

### Круглое отверстие и картина Эйри

Симметричная картина с центральным светлым кружком и системой колец. Радиус первого тёмного кольца `r₁ = 1.22 λL/D` – фундаментальный предел разрешения оптических приборов (критерий Рэлея).

### Хроматическая дисперсия (RGB-режим)

В режиме RGB на решётке хорошо видно, что разные длины волн отклоняются на разные углы: красный – больше, синий – меньше. Это объясняет, почему компакт-диск или дифракционная решётка играют радугой.

## Вывод

В данной работе создана программа, моделирующая дифракцию Фраунгофера от двумерного объекта произвольной формы. В основе расчёта – двумерное преобразование Фурье от амплитудного пропускания, реализованное собственным алгоритмом БПФ Кули–Тьюки с распараллеливанием по ядрам процессора.

Программа позволяет:

- интерактивно менять длину волны, расстояние до экрана, форму и размеры апертуры;
- проверять физику на тестовых случаях с известными решениями (прямоугольник, круг, двойная щель, решётка);
- наблюдать хроматическую дисперсию в RGB-режиме;
- рисовать произвольную маску мышью и сразу видеть её дифракционную картину.
