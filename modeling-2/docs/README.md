# Моделирование дифракции Фраунгофера

## Описание работы

В данной лабораторной работе реализована программа для моделирования **дифракции Фраунгофера** от двумерного объекта произвольной формы. Объект задаётся амплитудной маской `t(x, y)` — это функция, которая в каждой точке плоскости объекта говорит, какая доля падающей световой волны проходит сквозь него (1 — прозрачно, 0 — непрозрачно).

Программа вычисляет распределение интенсивности `I(X, Y)` в плоскости наблюдения, расположенной на расстоянии `L` от объекта, при освещении плоской монохроматической волной с длиной `λ`.

В программе задаются:

- `λ` — длина волны падающего излучения,
- `L` — расстояние до плоскости наблюдения,
- `N` — размер расчётной сетки (256, 512 или 1024),
- форма апертуры и её геометрические параметры (`W`, `H`, `T`, число щелей).

---

## Физическая основа работы

Дифракция Фраунгофера — это явление дифракции в **дальней зоне**: волна, прошедшая сквозь объект, отойдя достаточно далеко, формирует на экране картину, которая математически связана с самим объектом через двумерное преобразование Фурье.

Условие применимости — малое число Френеля:

`N_F = a² / (λ · L) ≪ 1`

где `a` — половина характерного размера апертуры. Если `N_F > 0.1`, мы выходим из режима дальней зоны и приближение Фраунгофера становится грубым. Программа сама вычисляет `N_F` и предупреждает, если он велик.

---

## Теоретические сведения

Распределение комплексной амплитуды поля в плоскости наблюдения:

```
U(X, Y) = [e^{ikL} · e^{ik(X²+Y²)/2L}] / (i·λ·L) · ∫∫ t(x, y) · exp(-i·2π·(Xx + Yy)/(λL)) dx dy
```

где `k = 2π/λ` — волновое число. Внутренний двойной интеграл — это и есть преобразование Фурье от `t(x, y)` на пространственных частотах `f_x = X/(λL)`, `f_y = Y/(λL)`.

Интенсивность, которую видит экран:

`I(X, Y) = |U(X, Y)|²`

При взятии квадрата модуля префакторы `e^{ikL}` и `e^{ik(X²+Y²)/2L}` исчезают (их модуль равен 1), поэтому форма картины полностью определяется модулем Фурье-образа маски.

### Канонические случаи

Для верификации программы используются формы, у которых дифракционная картина имеет известное аналитическое выражение:

- **Прямоугольное отверстие** `a × b`: `I ∝ sinc²(aX/λL) · sinc²(bY/λL)`,
- **Круглое отверстие** радиуса `R`: картина Эйри `I ∝ [2J₁(v)/v]²`, где `v = 2π·R·r/(λL)`. Первое тёмное кольцо при `r = 1.22·λL/D`,
- **Двойная щель** (опыт Юнга): `I ∝ sinc²(aX/λL) · cos²(π·d·X/λL)`,
- **Дифракционная решётка** из `N` щелей с периодом `d`: главные максимумы в направлениях `sin θ_m = mλ/d`.

Все эти картины воспроизводятся в программе при выборе соответствующего пресета.

## Дискретизация и численный метод

Маска `t(x, y)` дискретизируется на сетке `N × N` с шагом `dx` по обеим осям. Преобразование Фурье вычисляется быстрым алгоритмом — БПФ (FFT, Fast Fourier Transform) Кули–Тьюки по основанию 2.

Связь между параметрами:

- размер апертуры: `N · dx`,
- шаг в плоскости наблюдения: `DX = λL / (N · dx)`,
- размер окна наблюдения: `W_obs = N · DX = λL / dx`.

Чтобы нулевая частота (центр картины) оказалась в центре сетки, к маске применяется шахматный множитель `(-1)^(m+n)` — это эквивалент `fftshift`, но выполняется за один проход.

### Размер сетки `N`

В программе доступны три значения: 256, 512, 1024.

- `N = 256` — быстрый предпросмотр,
- `N = 512` — рабочий режим (по умолчанию),
- `N = 1024` — высокая детализация, видны слабые порядки дифракции.

## Что именно показывает программа

На экране отображаются:

- **левая панель** — амплитудная маска `t(x, y)` (объект, через который проходит свет);
- **правая панель** — распределение интенсивности `I(X, Y)` в плоскости наблюдения;
- **строка статуса** — текущие значения `λ`, `L`, `N`, число Френеля `N_F`, параметры апертуры и время пересчёта одного кадра.

### Цветовое отображение

Поддерживаются два режима:

1. **Монохромный** (`mono+plasma`) — одна длина волны, интенсивность раскрашивается палитрой "plasma" (от фиолетового через красный к жёлтому). Точно соответствует физике эксперимента с лазером одного цвета.
2. **RGB** — параллельный расчёт картины для трёх длин волн (650, 550, 450 нм) и наложение их в каналы R, G, B одного изображения. В этом режиме на дифракционной решётке видна **хроматическая дисперсия** — порядки дифракции "разваливаются" в радугу, потому что разные λ дают разные углы.

### Преобразование яркости

Дифракционная картина имеет очень большой динамический диапазон: центральное пятно бывает в тысячи раз ярче боковых порядков. Для того чтобы слабые порядки были видны, применяется одно из трёх преобразований:

- `log` — логарифмическое сжатие `disp = log(1 + α·I/I_max) / log(1 + α)`,
- `gamma` — степенное преобразование `disp = (I/I_max)^(1/γ)`,
- `linear` — линейная шкала (видно только самые яркие пятна).

- `λ = 550 нм` (зелёный),
- `L = 0.50 м`,
- `dx = 1 мкм`,
- `N = 512`,
- апертура — прямоугольник `60 мкм × 40 мкм`.

При этих значениях окно наблюдения составляет около 275 мкм, шаг ~0.5 мкм/пиксель.

## Управление программой

### Выбор апертуры

- `1` — прямоугольник,
- `2` — круг,
- `3` — двойная щель (опыт Юнга),
- `4` — дифракционная решётка,
- `5` — крест,
- `6` — кольцо,
- `M` — paint mode (рисование маски мышью).

### Параметры формы

- `W / Shift + W` — параметр `W` (ширина прямоугольника, радиус круга/кольца, ширина щели);
- `H / Shift + H` — параметр `H` (высота прямоугольника, высота щели);
- `T / Shift + T` — параметр `T` (расстояние между щелями, период решётки, внутренний радиус кольца);
- `[ / ]` — уменьшить / увеличить число щелей в решётке.

### Физические параметры

- `+ / -` — изменить длину волны,
- `L / Shift + L` — увеличить / уменьшить расстояние до экрана,
- `N` — переключить размер сетки (256 → 512 → 1024 → 256 …).

### Режим отображения

- `C` — переключить mono ↔ RGB,
- `D` — переключить log → gamma → linear,
- `G / Shift + G` — увеличить / уменьшить параметр `γ`.

### Прочее

- `S` — сохранить дифракционную картину в PNG;
- `R` — сброс параметров (в paint mode — очистка маски);
- в paint mode: левая кнопка мыши — рисовать, правая — стирать.

## Физический смысл получаемой картины

### Соотношение размеров

Чем уже отверстие, тем шире дифракционная картина — это фундаментальное свойство преобразования Фурье. Узкий прямоугольник в плоскости объекта даёт растянутую `sinc`-картину поперёк него, и наоборот.

### Двойная щель и решётка

Для двух щелей видны параллельные тёмные полосы — интерференция от двух источников. Расстояние между полосами обратно пропорционально расстоянию между щелями. Для дифракционной решётки тёмные полосы вырождаются в резкие точечные максимумы, и чем больше щелей, тем тоньше эти максимумы — это используется в спектроскопии.

### Круглое отверстие и картина Эйри

Симметричная картина с центральным светлым кружком и системой колец. Радиус первого тёмного кольца `r₁ = 1.22 λL/D` — фундаментальный предел разрешения оптических приборов (критерий Рэлея).

### Хроматическая дисперсия (RGB-режим)

В режиме RGB на решётке хорошо видно, что разные длины волн отклоняются на разные углы: красный — больше, синий — меньше. Это объясняет, почему компакт-диск или дифракционная решётка играют радугой.

## Используемые технологии

- язык программирования **Go**;
- библиотека **Ebiten** для графического отображения;
- собственная реализация FFT (Cooley–Tukey radix-2 DIT) — без внешних зависимостей по математике;
- многопоточность через `sync.WaitGroup` — параллельный расчёт строк/столбцов FFT и пиксельных буферов по числу ядер процессора.

## Запуск программы

### Установка зависимостей

```bash
go mod tidy
```

### Запуск

```bash
go run ./cmd/diffraction
```

или сборка отдельного бинарника:

```bash
go build -o diffraction ./cmd/diffraction
./diffraction
```

### Запуск тестов

В программе есть автоматические тесты, которые проверяют корректность FFT и точное положение нулей в `sinc²`-картине:

```bash
go test ./cmd/diffraction/
```

### Бенчмарк скорости

```bash
go test ./cmd/diffraction/ -bench=BenchmarkFFT2D -run=^$ -benchtime=5x
```

На современном процессоре время одного пересчёта картины:

- `N = 256` — менее 5 мс,
- `N = 512` — порядка 10–15 мс,
- `N = 1024` — порядка 30–60 мс.

Это удовлетворяет требованию интерактивности (картина обновляется при изменении параметров мгновенно, без заметной задержки).

## Вывод

В данной работе создана программа, моделирующая дифракцию Фраунгофера от двумерного объекта произвольной формы. В основе расчёта — двумерное преобразование Фурье от амплитудного пропускания, реализованное собственным алгоритмом БПФ Кули–Тьюки с распараллеливанием по ядрам процессора.

Программа позволяет:

- интерактивно менять длину волны, расстояние до экрана, форму и размеры апертуры;
- проверять физику на тестовых случаях с известными решениями (прямоугольник, круг, двойная щель, решётка);
- наблюдать хроматическую дисперсию в RGB-режиме;
- рисовать произвольную маску мышью и сразу видеть её дифракционную картину.
