# Fraunhofer Diffraction Simulation
## Техническая документация

---

## 1. Цель работы

Целью проекта является разработка численной модели **дифракции Фраунгофера** от двумерного объекта произвольной формы и создание интерактивной визуализации, позволяющей исследовать распределение интенсивности света в плоскости наблюдения.

Программа позволяет пользователю изменять параметры падающего излучения (длину волны, расстояние до экрана) и геометрию апертуры, и сразу наблюдать, как меняется дифракционная картина. Семь канонических пресетов (прямоугольник, круг, двойная щель, решётка, крест, кольцо, paint mode) перекрывают как тестовые случаи с известными аналитическими решениями, так и общий случай произвольной маски, нарисованной мышью.

Результат можно сохранить в `PNG`-файл.

---

## 2. Физическая модель

### 2.1. Объект моделирования

Моделируется дифракция плоской монохроматической волны на двумерном объекте, описываемом **амплитудной маской** `t(x, y)` – функцией, описывающей, как объект преобразует амплитуду проходящей волны в каждой точке:

- `t = 1` – точка полностью прозрачна;
- `t = 0` – точка полностью непрозрачна;
- промежуточные значения – частичная прозрачность.

В программе используются только вещественные значения `t ∈ [0, 1]` – чистая амплитудная маска без фазового пропускания.

Параметры модели:

- **λ** – длина волны падающего излучения (видимый диапазон 380–780 нм);
- **L** – расстояние до плоскости наблюдения (5 см … 5 м);
- **N** – размер расчётной сетки (256, 512 или 1024 – степень двойки);
- **dx** – физический шаг сетки в плоскости объекта (по умолчанию 1 мкм);
- форма и геометрические параметры апертуры (**apW**, **apH**, **apD**, **apNSlits**).

### 2.2. Принцип Гюйгенса–Френеля и интеграл Кирхгофа

Базовый постулат волновой оптики: каждая точка волнового фронта является источником вторичных сферических волн. Поле в любой точке за объектом – суперпозиция вкладов от всех точек объекта с учётом фаз.

Для плоской волны единичной амплитуды, падающей перпендикулярно объекту, поле в точке `(X, Y)` экрана даёт **интеграл Кирхгофа**:

$
U(X, Y) = \frac{1}{i\lambda} \iint t(x, y) \, \frac{e^{i k r}}{r} \cos\alpha \, dx \, dy,
$

где `r = √((X−x)² + (Y−y)² + L²)`, `α` – угол между нормалью к объекту и направлением на точку наблюдения, `k = 2π/λ` – волновое число.

### 2.3. Приближение Фраунгофера (дальняя зона)

При `L ≫ √((X−x)² + (Y−y)²)` экспоненту в подынтегральном выражении можно разложить:

$
r \approx L + \frac{X^2 + Y^2}{2L} - \frac{Xx + Yy}{L} + \frac{x^2 + y^2}{2L} + \ldots
$

Если последним слагаемым `(x² + y²)/(2L)` можно пренебречь – это и есть **условие Фраунгофера** – интеграл становится двумерным преобразованием Фурье:

$
U(X, Y) = \frac{e^{i k L} \, e^{i k (X^2 + Y^2)/(2L)}}{i \lambda L}
\iint t(x, y) \exp\!\left(-i \frac{2\pi (Xx + Yy)}{\lambda L}\right) dx \, dy.
$

Подынтегральное выражение – двумерное преобразование Фурье от маски `t(x, y)` на пространственных частотах:

$
f_x = \frac{X}{\lambda L}, \qquad f_y = \frac{Y}{\lambda L}.
$

Префакторы перед интегралом по модулю равны единице (`|e^{iφ}| = 1`) или константе (`|1/(iλL)| = 1/(λL)`). Они не зависят от `(x, y)` и поэтому не влияют на **форму** картины – это сознательное упрощение, и в коде они не вычисляются.

### 2.4. Распределение интенсивности

Фотодетектор (глаз, фотоплёнка, CCD) измеряет квадрат модуля поля:

$
I(X, Y) = |U(X, Y)|^2 \propto \left|\mathcal{F}[t]\!\left(\frac{X}{\lambda L}, \frac{Y}{\lambda L}\right)\right|^2.
$

При взятии квадрата модуля префакторы исчезают, и форма картины полностью определяется Фурье-образом маски.

### 2.5. Число Френеля – критерий применимости

$
N_F = \frac{a^2}{\lambda L},
$

где `a` – половина характерного размера апертуры (в коде `a = max(apW, apH)/2`).

- `N_F ≪ 1` – дальняя зона, работает формула Фраунгофера;
- `N_F ~ 1` – средняя зона (Френель), нужна более полная формула с квадратичной фазой;
- `N_F ≫ 1` – почти геометрическая оптика.

В программе порог `0.1`: при превышении выводится жёлтое предупреждение «far field broken».

## 3. Математическая модель

Непрерывный двойной интеграл заменяется конечной суммой. Объект разбивается на сетку `N × N` пикселей с шагом `dx`. Дискретное преобразование Фурье:

$
T(k_x, k_y) = \sum_{i, j} t(i, j) \, \exp\!\left(-i \frac{2\pi (k_x i + k_y j)}{N}\right).
$

Для каждой точки сетки в плоскости наблюдения:

1. строится дискретная амплитудная маска `t[i, j]`;
2. выполняется двумерное БПФ;
3. вычисляется квадрат модуля Фурье-образа `I = |U|² = Re² + Im²`;
4. результат нормируется на максимум;
5. применяется одно из преобразований яркости (log / gamma / linear);
6. результат раскрашивается палитрой (mono+plasma или RGB).

### Связь параметров сетки и физических координат

По свойствам ДПФ шаг по пространственной частоте равен `1/(N·dx)`. Подставляя в `f_x = X/(λL)`, получаем шаг по `X` в плоскости наблюдения и полное окно наблюдения:

$
\Delta X = \frac{\lambda L}{N \, dx},
\qquad
W_{obs} = N \, \Delta X = \frac{\lambda L}{dx}.
$

Окно наблюдения **не зависит от `N`** – оно определяется только `λ`, `L` и `dx`. При увеличении `N` (на том же `dx`) окно остаётся прежним, но детализация удваивается.

## 4. Численный метод

### 4.1. Пространственная сетка

Поле вычисляется на квадратной сетке `N × N`, где `N` – степень двойки:

- `N = 256` – быстрый предпросмотр (< 5 мс);
- `N = 512` – рабочий режим по умолчанию (10–15 мс);
- `N = 1024` – высокая детализация (30–60 мс).

Прямое вычисление ДПФ на сетке `N × N` требует `O(N⁴)` операций – для `N = 512` это `~7·10¹⁰` операций, недостижимо для интерактивной программы. Поэтому используется БПФ.

### 4.2. Быстрое преобразование Фурье Кули–Тьюки

Двумерное БПФ реализуется собственной реализацией алгоритма **Кули–Тьюки** (radix-2 DIT) без внешних научных библиотек.

Идея: `N`-точечное ДПФ разбивается на два `N/2`-точечных через рекурсивное деление массива на чётные и нечётные индексы. Сложность сокращается с `O(N²)` до `O(N log N)`, для 2D-картины – с `O(N⁴)` до `O(N² log N)`. Для `N = 512` это ускорение почти в 30 000 раз.

Реализация состоит из четырёх частей:

**1) Twiddle-факторы** `w_k = e^{−i·2π·k/N}` – поворотные комплексные множители «бабочек». Кешируются один раз для каждого `N`, чтобы синусы и косинусы не пересчитывались на каждый кадр:

```go
func twiddles(N int) []complex128 {
    twiddleMu.Lock(); defer twiddleMu.Unlock()
    if t, ok := twiddleCache[N]; ok { return t }
    t := make([]complex128, N/2)
    for k := 0; k < N/2; k++ {
        theta := -2 * math.Pi * float64(k) / float64(N)
        t[k] = complex(math.Cos(theta), math.Sin(theta))
    }
    twiddleCache[N] = t
    return t
}
```

**2) Bit-reverse permutation** – перестановка элементов в битово-обращённом порядке. Это требование итеративной версии Кули–Тьюки: после рекурсивного разбиения чётные/нечётные элементы оказываются на «зеркальных» позициях. Без перестановки `fft1D` выдаст результат с переставленными бинами.

**3) Бабочка (butterfly)** – элементарная in-place операция:

```go
for size := 2; size <= N; size <<= 1 {
    half := size >> 1
    step := N / size
    for i := 0; i < N; i += size {
        for k := 0; k < half; k++ {
            t := tw[k*step] * data[i+k+half]
            u := data[i+k]
            data[i+k]      = u + t
            data[i+k+half] = u - t
        }
    }
}
```

На каждой стадии `log₂ N` бабочек объединяют половины массива с поворотом на twiddle-угол.

**4) Двумерное БПФ** факторизуется математически точно: сначала одномерное БПФ по каждой строке, потом – по каждому столбцу. Это позволяет параллельно обрабатывать строки/столбцы через `sync.WaitGroup` на `runtime.NumCPU()` горутин:

```go
for w := 0; w < nWorkers; w++ {
    wg.Add(1)
    go func(s, e int) {
        defer wg.Done()
        for r := s; r < e; r++ { fft1D(data[r*N:(r+1)*N], tw) }
    }(start, end)
}
wg.Wait()
```

На 8-ядерном CPU параллелизм даёт ускорение в `~NumCPU` раз: при `N = 1024` это разница между 30 мс и 240 мс.

### 4.3. Центрирование нулевой частоты (fftshift)

Стандартное БПФ кладёт нулевую частоту (центр картины) в индекс `0`, высокие частоты – в середину массива. Классическое решение – `fftshift`: перестановка четырёх квадрантов после БПФ, требующая дополнительного прохода по памяти.

Здесь используется математически эквивалентный, но более дешёвый трюк: умножение **входной** маски на шахматный паттерн `(−1)^(i+j)`.

```go
if (i+j)&1 == 1 { v = -v }
```

Свойство ДПФ: умножение в пространственной области на `e^{iπn} = (−1)^n` сдвигает спектр на `N/2`. Применяя по обоим измерениям, центрируем результат за один проход во время заполнения маски. Корректность подтверждается тестом `TestFFT2DCheckerboardCentersDC`.

### 4.4. Нормировка интенсивности на `I_max`

Абсолютная яркость интенсивности после БПФ не имеет физического смысла: префакторы Фраунгофер-формулы отброшены. Программа находит максимум по всему полю и работает с относительной интенсивностью `I / I_max ∈ [0, 1]`:

```go
Imax := 0.0
for _, v := range g.intensity {
    if v > Imax { Imax = v }
}
if Imax <= 0 { Imax = 1 }
```

Защитное условие исключает деление на ноль для вырожденного случая «всё чёрное».

### 4.5. Преобразование яркости

Дифракционная картина имеет огромный динамический диапазон: центральное пятно бывает в `10³–10⁴` раз ярче боковых порядков. Линейное отображение `I/I_max → пиксель` даст почти чёрное поле с одной яркой точкой – слабые порядки утонут в квантовании 8-битного канала.

```go
switch mode {
case dispLog:
    return math.Log1p(logAlpha*v) / math.Log1p(logAlpha)
case dispGamma:
    return math.Pow(v, 1.0/gamma)
default:
    return v
}
```

- **`log`**: `disp = log(1 + α·v) / log(1 + α)`, `α = 10³` – самый агрессивный режим, показывает порядки в `10⁴` раз слабее центра;
- **`gamma`**: `disp = v^(1/γ)`, `γ ∈ [1, 6]` – мягче, ближе к sRGB-коррекции (γ ≈ 2.2);
- **`linear`**: `disp = v` – без сжатия.

## 5. Канонические апертуры и их аналитические картины

Все семь пресетов реализуются в функции `buildAperture` через `switch` по типу.

### 5.1. Прямоугольное отверстие

Маска `t = 1` внутри прямоугольника `apW × apH`. Аналитическая картина:

$
I(X, Y) \propto \mathrm{sinc}^2\!\left(\frac{apW \cdot X}{\lambda L}\right) \cdot \mathrm{sinc}^2\!\left(\frac{apH \cdot Y}{\lambda L}\right),
$

где `sinc(u) = sin(πu)/(πu)`. Первые нули по `X` – на расстоянии `λL/apW` от центра. Тестируется автоматически в `TestFFT2DRectSincZero`.

### 5.2. Круглое отверстие – картина Эйри

$
I \propto \left[\frac{2 J_1(v)}{v}\right]^2,
\qquad
v = \frac{\pi \cdot apW \cdot r}{\lambda L},
$

где `J₁` – функция Бесселя первого рода. Первое тёмное кольцо: `r₁ = 1.22 λL/apW` – **критерий Рэлея**, фундаментальный предел разрешения телескопов и микроскопов.

### 5.3. Двойная щель (опыт Юнга)

Две щели шириной `apW` с центрами в `±apD/2`. Аналитическая картина:

$
I(X, Y) \propto \mathrm{sinc}^2\!\left(\frac{apW \cdot X}{\lambda L}\right) \cdot \cos^2\!\left(\frac{\pi \cdot apD \cdot X}{\lambda L}\right).
$

Период интерференционных полос: `λL/apD`. Увеличение `apD` сжимает полосы – знаменитый эффект Юнга.

### 5.4. Дифракционная решётка

`apNSlits` одинаковых щелей шириной `apW` с периодом `apD`. Главные максимумы:

$
\sin \theta_m = \frac{m \lambda}{apD}, \quad m = 0, \pm 1, \pm 2, \ldots
$

Ширина главных максимумов пропорциональна `1/apNSlits` – чем больше щелей, тем острее пики. Это и есть принцип спектроскопа: больше штрихов → выше разрешающая способность по `λ`.

### 5.5. Крест

Объединение двух перпендикулярных прямоугольников (логическое ИЛИ). Дифракционная картина – наложение двух перпендикулярных `sinc²`-полос.

### 5.6. Кольцо (annulus)

Внешний радиус `apW/2`, внутренний `apD/2`. Картина – разность двух картин Эйри. При `apD → apW` асимптотически переходит в `J₀²(π·apW·r/λL)` – модель телескопа Кассегрена с центральным экраном.

### 5.7. Paint mode – произвольная маска

Маска задаётся пользователем мышью: ЛКМ – рисовать (t = 1), ПКМ – стирать (t = 0). Радиус «штампа» – `N/64` пикселей. От прошлой позиции мыши к текущей растеризуется отрезок, чтобы при быстром движении не оставались дыры. Это и есть ответ на исходное требование задачи: «объекты произвольной формы». Все остальные пресеты – лишь тесты с известным аналитическим решением для верификации общего метода.

## 6. Формирование результата

### 6.1. Визуализация (mono+plasma)

В моно-режиме одна длина волны, и интенсивность раскрашивается палитрой "plasma" – перцептуально равномерной (от тёмно-фиолетового через красный к жёлтому), стандартной для научной визуализации. Между опорными точками – линейная RGB-интерполяция.

### 6.2. RGB-режим – хроматическая дисперсия

При нажатии `C` программа имитирует освещение объекта одновременно тремя длинами волн: `λ_R = 650 нм`, `λ_G = 550 нм`, `λ_B = 450 нм`. БПФ вычисляется **только один раз** (при текущей `λ`), потому что `|U|²` сама по себе не зависит от длины волны – `λ` входит только в связь между индексом массива и физической координатой:

$
X(k) = (k - N/2) \cdot \frac{\lambda L}{N \, dx}.
$

Чтобы получить интенсивность для длины волны `λ_c` в той же физической точке `X`, индекс масштабируется:

$
k_c = \frac{N}{2} + (j - \frac{N}{2}) \cdot \frac{\lambda_R}{\lambda_c}.
$

Для красного `scale = 1`, для синего `scale ≈ 1.44`. Поскольку индекс получается нецелым, применяется **билинейная интерполяция** между четырьмя соседними отсчётами FFT – без неё в RGB-картине появится пиксельный шум, особенно у синего канала.

Физический результат: на дифракционной решётке порядки расходятся в радугу (как на CD-диске), потому что `sin θ_m = m·λ/d` зависит от длины волны.

### 6.3. Сохранение в PNG

По нажатию `S` дифракционная картина сохраняется в PNG-файл.

## 7. Интерактивное управление

Приложение использует библиотеку `Ebiten` для графического отображения.

### Выбор апертуры

| Клавиша | Действие |
|---------|----------|
| `1` | Прямоугольное отверстие |
| `2` | Круглое отверстие |
| `3` | Двойная щель (опыт Юнга) |
| `4` | Дифракционная решётка |
| `5` | Крест |
| `6` | Кольцо |
| `M` | Paint mode (рисование маски мышью) |

### Параметры формы

| Клавиша | Параметр |
|---------|----------|
| `W / Shift+W` | `apW` (ширина / радиус / ширина щели) |
| `H / Shift+H` | `apH` (высота / высота щели) |
| `T / Shift+T` | `apD` (расстояние между щелями / период решётки / внутренний радиус кольца) |
| `[ / ]` | число щелей в решётке (2–64) |

### Физические параметры

| Клавиша | Параметр |
|---------|----------|
| `+ / -` | длина волны `λ` (380–780 нм, шаг 10 нм) |
| `L / Shift+L` | расстояние до экрана `L` (5 см … 5 м, шаг 5 см) |
| `N` | размер сетки (256 → 512 → 1024 → 256 …) |

### Режим отображения

| Клавиша | Действие |
|---------|----------|
| `C` | mono ↔ RGB |
| `D` | log → gamma → linear |
| `G / Shift+G` | параметр `γ` (1.0–6.0, шаг 0.1) |

### Прочее

| Клавиша | Действие |
|---------|----------|
| `S` | сохранить картину в PNG |
| `R` | сброс параметров (в paint mode – очистка маски) |

После выполнения расчёта пользователь видит в строке статуса: текущие значения `λ`, `L`, `N`, число Френеля `N_F`, размер окна наблюдения `W_obs`, время пересчёта одного кадра.

### Основные компоненты

- [cmd/diffraction/main.go](cmd/diffraction/main.go) – основной файл: физическая модель, реализация БПФ, построение маски, графический вывод.
- [cmd/diffraction/fft_test.go](cmd/diffraction/fft_test.go) – автоматические тесты корректности БПФ и положения нулей в `sinc²`-картине.
- [cmd/diffraction/bench_test.go](cmd/diffraction/bench_test.go) – бенчмарк скорости двумерного БПФ.
- [docs/](docs/) – расширенная теоретическая документация и план защиты работы.

### Основные структуры и функции

- **Game** – главное состояние приложения (параметры, буферы, текущая маска).
- **buildAperture()** – строит дискретную амплитудную маску для выбранного пресета.
- **twiddles() / bitReverse() / fft1D() / fft2D()** – реализация БПФ Кули–Тьюки.
- **parallelFor()** – параллельный цикл по числу ядер.
- **transformIntensity()** – преобразование яркости (log / gamma / linear).
- **plasmaColor() / bilinear()** – палитра для моно-режима и интерполяция для RGB.

Такое разделение удобно для защиты, потому что физика, численный метод и интерфейс отделены друг от друга. Весь FFT-код умещается в ~50 строк, без внешних математических зависимостей; единственная внешняя библиотека – Ebiten для графики.

## 9. Принцип работы симуляции (алгоритм)

Полная цепочка вычислений:

```
амплитудная маска t(x, y)            ← buildAperture
       ↓ умножение на (−1)^{i+j}     ← inline в buildAperture: fftshift трюком
двумерное БПФ                        ← fft2D: строки → столбцы, параллельно
       ↓
комплексное поле U(X, Y)             ← в массиве fftBuf
       ↓ |·|²
интенсивность I(X, Y) = |U|²         ← parallelFor: re² + im²
       ↓ деление на I_max
относительная интенсивность ∈ [0,1]
       ↓ log / gamma / linear
яркость пикселя disp ∈ [0,1]         ← transformIntensity
       ↓
plasma colormap (mono) ИЛИ RGB-выборка с bilinear
       ↓
финальное изображение                ← ebiten.Image, отрисовка
```

Время одного полного пересчёта на современном CPU:

| `N` | Время пересчёта |
|-----|----------------|
| 256 | < 5 мс |
| 512 | 10–15 мс (рабочий режим) |
| 1024 | 30–60 мс |

Это обеспечивает интерактивность: пользователь нажимает клавишу – картина обновляется без заметной задержки.

## 10. Корректность: автоматические тесты

В `cmd/diffraction/fft_test.go` пять тестов:

| Тест | Что проверяет | Физика |
|------|--------------|--------|
| `TestFFT1DImpulse` | FFT от δ-импульса = плоский спектр | Дельта-функция имеет постоянный Фурье-образ |
| `TestFFT1DConstant` | FFT от константы = пик в DC, остальное ноль | Постоянная функция имеет Фурье-образ δ(f) |
| `TestFFT1DSine` | FFT от `e^{i·2π·k₀·n/N}` имеет пик в бине `k₀` | Гармоника в спектре – это один бин |
| `TestFFT2DRectSincZero` | Первый нуль `sinc²` от прямоугольника в предсказанном бине | Аналитика прямоугольной апертуры |
| `TestFFT2DCheckerboardCentersDC` | После шахматного множителя пик от константы – в `(N/2, N/2)` | Корректность fftshift-трюка |

Первые три проверяют базовую корректность 1D-БПФ против аналитических формул. Четвёртый – общую корректность 2D-БПФ на нетривиальной маске. Пятый – корректность fftshift-трюка с шахматным множителем.

## 11. Визуальная часть

Интерфейс содержит:

- **левую панель** с амплитудной маской `t(x, y)` (объект, через который проходит свет);
- **правую панель** с распределением интенсивности `I(X, Y)` в плоскости наблюдения;
- **строку статуса** с текущими значениями `λ`, `L`, `N`, числом Френеля `N_F`, размером окна наблюдения `W_obs` и временем пересчёта;
- **предупреждение** «far field broken», если `N_F > 0.1`.

На итоговом изображении видны:

- классические дифракционные картины для семи пресетов апертур;
- хроматическая дисперсия в RGB-режиме (порядки решётки расходятся в радугу);
- слабые порядки в режиме log-преобразования яркости;
- центральная симметрия картины Эйри с известным радиусом первого тёмного кольца `r₁ = 1.22 λL/D`;
- произвольные узоры в paint mode для любой нарисованной маски.

## 12. Выводы

Разработанная программа моделирует дифракцию Фраунгофера от двумерного объекта произвольной формы. В основе расчёта – двумерное преобразование Фурье от амплитудного пропускания, реализованное собственным алгоритмом БПФ Кули–Тьюки (radix-2 DIT) с распараллеливанием по ядрам процессора.

Использованный численный метод обеспечивает:

- корректный расчёт двумерного преобразования Фурье без внешних научных библиотек;
- автоматическую верификацию через пять тестов с аналитическими формулами;
- интерактивный пересчёт картины (< 60 мс даже для `N = 1024`);
- наглядную визуализацию с log/gamma-преобразованием для большого динамического диапазона;
- хроматическую дисперсию в RGB-режиме;
- контроль области применимости через число Френеля.

Проект может использоваться как учебный инструмент по темам:

- дифракция Фраунгофера и приближение дальней зоны;
- принцип Гюйгенса–Френеля и интеграл Кирхгофа;
- двумерное преобразование Фурье в оптике;
- численные методы (БПФ Кули–Тьюки, fftshift, параллелизм);
- интерферометрия и спектроскопия (опыт Юнга, дифракционная решётка);
- критерий Рэлея и разрешающая способность оптических приборов;
- хроматическая дисперсия и принцип работы CD-диска.

## 13. Запуск

Установка зависимостей:

```bash
go mod tidy
```

Запуск приложения:

```bash
go run ./cmd/diffraction
```

Или сборка отдельного бинарника:

```bash
go build -o diffraction ./cmd/diffraction
./diffraction
```

Запуск тестов:

```bash
go test ./cmd/diffraction/
```

Бенчмарк скорости БПФ:

```bash
go test ./cmd/diffraction/ -bench=BenchmarkFFT2D -run=^$ -benchtime=5x
```
